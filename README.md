# Stream Buddy

Stream Buddy te ayuda a preparar tus directos de TikTok desde Windows. Lee comentarios en voz alta y muestra en pantalla alertas, clasificaciones de likes y regalos, o la canción que estás escuchando.

## Instala Stream Buddy

1. Descarga **StreamBuddy-Setup.exe** para Windows de 64 bits.
2. Abre el archivo y sigue los pasos del instalador.
3. Busca **Stream Buddy** en el menú Inicio y ábrelo.

Si ya usabas Stream Buddy, puedes importar tus perfiles y escenas al abrirlo por primera vez. Elige la carpeta donde tenías la versión anterior.

## Prepara tu primer directo

1. Pulsa **Conectar TikTok**, escribe tu nombre de usuario y pulsa **Conectar** cuando estés en directo.
2. En **Voz y chat**, escribe un texto de prueba y pulsa **Probar estos ajustes** para escucharlo. La voz española Lola viene incluida. La primera vez que uses otra voz de Pocket TTS, necesitarás Internet para descargarla.
3. Elige qué quieres mostrar, por ejemplo **Notificaciones**, **Top likes** o una escena con marcos para tu cámara y tu juego.

## Muestra un overlay en tu directo

Un overlay es un elemento que aparece encima del vídeo, como una alerta o un marco para tu cámara.

1. En Stream Buddy, abre el elemento que quieras mostrar y pulsa **Copiar salida**.
2. En TikTok LIVE Studio, añade una fuente de **Enlace**. En OBS, añade una fuente de **Navegador**. Pega el enlace que copiaste.
3. Mantén Stream Buddy abierto mientras transmites.

Si solo quieres preparar el diseño, puedes editar tus escenas y probar la voz sin conectarte a TikTok.

## Perfiles y actualizaciones

Usa **Perfil local** si quieres guardar voces, escenas y ajustes distintos para cada canal o tipo de directo.

Para buscar una nueva versión, abre el menú **Stream Buddy** y elige **Buscar actualizaciones**. Si estás transmitiendo, elige **Más tarde** para que los overlays sigan funcionando.
